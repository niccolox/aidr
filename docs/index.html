AIDR

A CLI that streams your agent's changes, code graphs, busywork, learnings and security.

Run it in a second terminal next to Claude Code. Each edit arrives with the reason Claude gave, the code it touches, and one question to answer before you accept the next one.

Install from source Read the code

  • Offline by default
  • No dependencies
  • Linux, macOS

Example output of aidr, drawn by its own code, for an invented shop session.

🤔 Claude Code writes faster than you read.

After an hour of work, your repository holds code that you did not write and may not be able to explain. A review at the end comes too late, because ten more edits already rest on the first one.

AIDR shows each change at the time Claude makes it, with the reason next to the lines. You read it while the context is fresh, and you keep the authority over your code.

🖥️ Two terminals, one folder.

  1. 1

    Install AIDR

    Clone the repository and link the command. Nothing else is downloaded.

  2. 2

    Start Claude Code

    Work in your project as usual. AIDR needs no plugin, no hook and no change to your settings.

  3. 3

    Run aidr beside it

    Open a second terminal in the same folder. Each step and each change streams in as Claude works.

📦 Install from source

The npm package devekko.aidr is not published yet. You need Node 20 or later and git.

Without npm link, run node /path/to/aidr/bin/aidr.mjs. To update, run git pull in the clone. To remove the command, run npm unlink -g devekko.aidr.

$ git clone https://github.com/niccolox/aidr.git
$ cd aidr
$ npm test     # no dependencies to install
$ npm link     # puts aidr on your PATH

$ cd ~/code/your-project
$ aidr

🧬 The Pydantic models a change touches.

In a Python project, AIDR lists the models in play for each edit: their fields, their links to other models, and the fields the change names. It reads the files with Python's ast module, so no code of your project runs.

In a terminal, AIDR draws the code graphs and the models itself. In a pipe or a file, it writes them as Mermaid text: paste it into a pull request or a document and GitHub draws it. In the watch, --mermaid adds the text.

aidr stage HEAD~3..HEAD gives the models and the code graph changes of a commit range: tables and drawings in a terminal, Markdown tables and Mermaid in a file.

📓 A journal of each day, week and month.

aidr journal reads the transcripts of the folder and its git history, and prints what happened: the sessions, the prompts, the changes planned, in process and completed, the commits, the tests that failed, the files and the Pydantic models that changed most.

aidr journal week and aidr journal month give one section for each day. aidr journal project gives the lifecycle of the folder: one row for each month, the tags, and when each top folder started.

It prints Markdown and writes no file: aidr journal week > week.md keeps it. No model writes it, so it opens no network connection.

💓 A heartbeat for every agent.

When Claude Code starts agents of its own, aidr agents draws the map: each session and each agent it started, with its state (running, quiet, stalled, finished or failed), its age, its steps, its last step, and for an agent in a git worktree its commits and open files. The watch prints the map when it starts and every 10 minutes.

🐚 With --commands, each shell step shows the command Claude ran under its description, with secrets masked. --agents prints the map at the start and every 10 minutes.

⌨️ Commands

aidrThe minimal watch: each step on one line, and each code change as one line with its file and line counts
aidr listThe Claude Code sessions in operation, once
aidr agents💓 The agent map: each agent, its state and its heartbeat
aidr stage a..bThe Pydantic models in play and the code graph changes of a commit range
aidr journal [day|week|month|project]A journal of the folder as Markdown; --date YYYY-MM-DD for another day; --learn --security adds the cards of the day
--code, --full-diffThe diff of each change with the reason, a note and a question; every changed line
--map, --ontologyThe code graph of each changed function; the Pydantic models of a Python change
--mermaidThe Mermaid text next to the drawings
--stage, --progressThe stage report after a commit; the time and last output of long commands
--agents💓 The agent map at the start and every 10 minutes
--commands🐚 The command lines of each shell step, secrets masked
--changes, --busyworkThe change events (planned, in process, completed); every step and text in full
--allEvery flag above. The flags add up: aidr --code --map --security
--globalEvery folder, not only this one
--learnA Learn card under each change: a memory aid, advice and official links, written by local Claude when the claude CLI is on your PATH, else by Gemma with your own Cloudflare keys
--securityA Security card under each change at a trust boundary: impact, threat, fix, the NIST SSDF v1.1 practice and a link, written by local Claude with Cloudflare's security-audit skill

🔒 It reads. It writes nothing.

The package is about 4,400 lines of JavaScript and Python, formatted with Biome, with no dependencies and no install script. Read it before you run it.

Reads

  • Your own processes, to find the Claude Code sessions.
  • The transcripts under ~/.claude/projects.
  • git in each session's folder, with read-only commands.
  • Python models with the ast module. No project code runs.

Never

  • Writes a file or sends telemetry. It opens no network connection unless you run --learn. A test checks the source for both.
  • Shows a private file: .env, SSH keys, cloud and Claude credentials, *.tfvars, and your own globs.
  • Prints a secret: tokens, keys, passwords and URL passwords are masked on every line.
  • Passes control bytes to your terminal, so a file cannot write to your clipboard.

❓ Questions

Does it send my code anywhere?
No, unless you ask for cards. Without --learn or --security, AIDR opens no network connection and starts no model. --learn sends the kind of change and the names of the changed function and models to your local claude CLI, or to Workers AI with your own key; the changed lines go only with --learn-code. --security sends the relative path and the changed lines to your local claude CLI. Secrets are masked first, and a private file is never sent.
Does it change my files or my sessions?
No. It reads transcripts and runs read-only git commands.
Does it work with other coding agents?
Not now. It reads the transcript format of Claude Code.
What do I need?
Node 20 or later and git, on Linux or macOS. python3 and codegraph are optional.
Is it on npm?
Not yet. Install it from source; the npm package devekko.aidr comes next.
Why AGPL-3.0?
You can use, change and share AIDR. If you share a changed version, or run one for others over a network, you share your changes too.
