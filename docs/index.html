See what Claude Code changed, and why.

aidr runs in a second terminal next to Claude Code. For each edit, it shows the diff, the reason Claude gave, a note on what to check, and one question to answer before you go on.

You stay the author of your code

Claude Code edits files faster than you can read them. After an hour of work, your repository holds code that you did not write and may not be able to explain. aidr puts each change in front of you at the time Claude makes it, with the reason next to the lines.

How it works

  1. Install aidr

    Clone the repository and link the command. There are no packages to download.

  2. Start Claude Code

    Work in your project as usual. aidr needs no plugin and no change to your settings.

  3. Run aidr beside it

    Open a second terminal in the same folder and type aidr. Each change shows as Claude makes it.

Install from source

The npm package devekko.aidr is not published yet. You need Node 20 or later and git.

git clone https://github.com/niccolox/aidr.git
cd aidr
npm test     # no dependencies to install
npm link     # puts the aidr command on your PATH

cd ~/code/your-project
aidr

Without npm link, run node /path/to/aidr/bin/aidr.mjs. To update, run git pull in the clone. To remove the command, run npm unlink -g devekko.aidr.

What it shows

CommandWhat you see
aidrEach step of the sessions in this folder, and each code change with the reason, a note and a question
aidr --changesOnly the significant changes: planned, in process and completed
aidr --busyworkThe raw log: every step, Claude's text and each prompt in full, as formatted Markdown
aidr listThe Claude Code sessions in operation, once
aidr stage HEAD~3..HEADThe Pydantic models in play and the CodeGraph changes of a commit or a range
aidr --globalEvery folder, not only this one

With CodeGraph and a .codegraph/ index, aidr draws the callers and callees of each changed function. With python3 on the PATH, it lists the Pydantic models that a change touches, with their fields and links. Long tool calls and background commands show their time and their last line of output.

It reads. It writes nothing.

aidr reads your own processes, the Claude Code transcripts under ~/.claude/projects, and git in each session's folder. It reads Python models with Python's ast module, so no code of your project runs.

  • It writes no file, opens no network connection, sends no telemetry and starts no server. A test checks the source for network and write calls.
  • It never shows a private file: .env files, SSH keys, cloud and Claude credentials, *.tfvars and more. You can add your own globs.
  • It masks tokens, keys, passwords and URL passwords in every line it prints.
  • It removes terminal control bytes, so a file or a prompt cannot write to your clipboard or change your screen.

The package is about 1,600 lines of JavaScript and Python, with no dependencies and no install script. Read it before you run it.

Questions

Does it send my code anywhere?
No. aidr opens no network connection.
Does it change my files or my sessions?
No. It only reads transcripts and runs read-only git commands.
Does it work with other coding agents?
Not now. It reads the transcript format of Claude Code.
What do I need?
Node 20 or later and git, on Linux or macOS. python3 and codegraph are optional.
Why AGPL-3.0?
You can use, change and share aidr. If you give a changed version to others, or run it for others over a network, you share your changes under the same licence.
